# Folder Asset Gambar

Folder ini digunakan untuk menyimpan seluruh asset gambar website LaNouvelle:

1. **Header / Navbar**:
   - `public/images/logo.png` (atau `.svg` / `.webp`) -> Logo brand di tengah Navbar.
2. **Hero Section (Part 1)**:
   - `public/images/hero-banner.jpg` -> Gambar utama di sisi kanan Hero Section.
3. **Produk Racing Series (Part 2 & 3)**:
   - `public/images/products/verstappen-kick.jpg` -> Gambar produk Verstappen Kick.
4. **Made for Your Everyday (Part 4)**:
   - `public/images/everyday-banner.jpg` -> Gambar close-up kaos / apparel di sisi kiri section Everyday.

*Catatan: Semua komponen sudah dilengkapi fallback visual placeholder yang rapi sehingga website tetap tampil cantik meskipun gambar belum diunggah.*
